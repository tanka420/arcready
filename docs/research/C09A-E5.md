## 3. Final analyzer contract

A reportable record is intentionally bounded to reviewed evidence:

- supported `.sol` source;
- exact PREVRANDAO source family;
- same-function bounded value dependency;
- approved selection, authorization, eligibility, allocation, recipient, winner,
  ordering, relay, relayer, validator, sequencer, or committee sink;
- one deterministic shell owner;
- exact concrete contract identity;
- retained Foundry broadcast ownership from
  `broadcast/<Script>.s.sol/<chainId>/run-latest.json`;
- exact Arc Testnet chain ID `5042002`;
- valid exact deployed contract address;
- no conflicting Arc/non-Arc ownership.

Unsupported or ambiguous evidence fails closed.

## 5. Supported grammar and explicit limits

C09A is not a general Solidity security analyzer, CFG engine, SSA engine, taint
engine, or symbolic executor.

The supported production surface remains deliberately narrow and fail-closed.
It does not claim support for arbitrary:

- cross-file or cross-contract value flow;
- inheritance, modifier, library, or imported-symbol resolution;
- mutation graphs, deep alias graphs, branch joins, loops, or recursion;
- generic Yul analysis;
- compiler-version inference;
- Hardhat or custom deployment adapters;
- live RPC, explorer, bytecode, transaction, or runtime verification.

Foundry evidence is static retained artifact evidence only. A finding does not
prove that a deployment is currently live, that bytecode matches a current
chain state, or that any transaction succeeded.

## 6. Compatibility-shell limitation and later trigger

The two public IDs are retained only for compatibility with existing wallet and
bridge preset contracts.

A later separately reviewed milestone may consolidate or retire one or both
shells when at least one of these conditions is met:

- usage evidence shows one shell has negligible material value;
- a stable existing preset can truthfully own the full supported finding surface;
- a versioned public migration can preserve configuration compatibility without
  silently losing coverage;
- real user evidence justifies a broader or different ownership model.

No shell consolidation should be bundled into C09A closeout.
